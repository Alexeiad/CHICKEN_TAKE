# Перевод меню: русский, английский и немецкий

## Как проверить

1. Вернись в Unity и дождись импорта и компиляции новых файлов.
2. Открой сцену `Assets/_Scenes/_Build/1_MAIN_MENU.unity`.
3. Нажми Play. Справа сверху появится кнопка языка.
4. Каждое нажатие переключает русский → английский → немецкий → русский.
5. Проверь главное меню, сохранения, авторов, звук, графику и настройки камеры. Выбор языка сохраняется между запусками через PlayerPrefs.

Кнопка создаётся скриптом при запуске, поэтому вне Play Mode её нет в Hierarchy.

## Где менять перевод

Выбери `Assets/_Data/MenuTranslations.asset` в окне Project. Это ScriptableObject — отдельный файл с данными, который редактируется в Inspector без изменения кода.

Раскрой Entries и нужную запись. Например:

| Поле | Значение |
|---|---|
| Key | playText |
| Russian | Играть |
| English | Play |
| German | Spielen |

Key — постоянное имя надписи. Оно должно совпадать с ключом в компоненте Menu Localization. Russian, English и German — тексты для игрока. Повторяющиеся подписи используют один ключ. Если перевод пустой, берётся русский текст; если ключ отсутствует в базе, на экране показывается сам ключ.

## Как устроено подключение

На корневом объекте префаба `Assets/_Prefabs/MENU_INSTANCE.prefab` добавлен компонент `MenuLocalization`:

- Translations — одна ссылка на базу `MenuTranslations.asset`.
- Texts — 26 записей с ключами и ссылками на надписи, включая вложенный блок камеры.
- Tmp Text — ссылка на компонент TextMeshPro. Legacy Text используется только для старых компонентов UI Text.
- Camera Mode Dropdown — список выбора вида камеры. Переводятся варианты списка; его выбранное значение и настройки камеры сохраняются.
- Menu Canvas и Language Font — место для кнопки языка и существующий шрифт Nunito с динамическим атласом.

Буквы клавиш V/C/Q и служебные шаблоны выпадающих списков не требуют отдельных переводов. Сами списки обновляют свои подписи.

## Как добавить надпись

1. Добавь в базу запись с новым уникальным Key и тремя переводами.
2. Открой MENU_INSTANCE и найди Menu Localization на его корне.
3. Добавь элемент в Texts, впиши тот же Key и перетащи компонент надписи в Tmp Text (или Legacy Text).
4. Запусти меню и проверь все три языка.

Для предварительного просмотра вне Play Mode выбери Language в компоненте и вызови `Refresh translations` из его контекстного меню. Изменения текста при таком просмотре могут пометить префаб изменённым. В игре сохранённый язык имеет приоритет над полем Language.

## Проверка реализации

Код скомпилирован компилятором из Unity 2022.3.55f1 с реальными ссылками проекта. Проверены ключи и ссылки новых привязок в YAML. Play Mode и визуальная проверка в редакторе не выполнялись: после импорта стоит проверить размещение кнопки и длинные немецкие подписи. Для подписей включается автоматическое уменьшение размера в существующих рамках.
